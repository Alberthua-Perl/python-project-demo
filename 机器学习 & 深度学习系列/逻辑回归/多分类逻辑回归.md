# 如何用多类别逻辑回归 (Logistic Regression with Multiple Classes) 解决多分类问题？

- 当想把二分类模型应用到多分类时，有两种实用的策略：
  - 1️⃣  一对其余 (One-vs-Rest, **OVR**) 策略：
    - 💡 策略：有多少个类别，就训练多少个二分类逻辑回归分类器。
    - 举个例子：
	  - 如果有 3 个类别 (Class 1, 2, 3)，就训练 3 个分类器：
        - 分类器 A：判断是 Class 1 还是非 Class 1
        - 分类器 B：判断是 Class 2 还是非 Class 2
        - 分类器 C：判断是 Class 3 还是非 Class 3
      - 🔑 结果：每个分类器都会给出一个分数。选择分数最高的那个类别作为最终输出。
  - 2️⃣  多项式逻辑回归 (Multinomial Logistic Regression)：
    - 💡策略：只建立一个模型，让它直接输出一个 “概率向量”。
    - 举个例子：
	  - 输入一张图片，模型直接告诉你：**[Class 1 的概率, Class 2 的概率, Class 3 的概率]**。
      - 🛠️ 秘诀：为了让这些输出值看起来像 “概率”（即大于 0，且加起来等于 1），模型内部使用了一个神奇的函数：Softmax 函数。这是深度学习中分类任务的标配。
      - 🎉 最终结果：选择概率最大的那个类别作为最终预测。
- 模型评估和假设 (Bonus Knowledge)：
  - 模型评估 (Model Evaluation)：
    - 准确率 (Accuracy)
    - 混淆矩阵 (Confusion Matrix)
  - 模型假设 (Assumptions)：
    - 结果是二元的或多重的 (Binary or Multiple Outcome)：表明结果是有限的类别
    - 独立性 (Independence)：数据点之间要相互独立
    - 多重共线性 (Multicollinearity)：特征（输入变量）之间不应该高度相关
    - 样本量 (Sample Size)：需要足够大的样本量才能得出可靠的结果
