LLM：最终的生成引擎

关键在于 Prompt 构造——引导模型「引用」而非「创作」

RAG Prompt 结构示意：
System Prompt
你是专业知识库问答助手。请严格基于【参考资料】回答，不要编造内容。如资料不足，请说明无法回答。
User Message — 参考资料
【资料1】（来源：HR-Policy.pdf）
年假制度：工作满1年享有10天年假……
【资料2】（来源：FAQ.txt）
年假申请需提前3个工作日……
User Message — 用户问题
年假可以申请几天？需要提前多久？
