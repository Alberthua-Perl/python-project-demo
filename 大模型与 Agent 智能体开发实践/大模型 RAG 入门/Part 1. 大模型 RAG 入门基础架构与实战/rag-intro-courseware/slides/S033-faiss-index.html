FAISS 索引：归一化 + 内积 = 余弦检索

IndexFlatIP + normalize_L2 是手写 RAG 的标准组合

📦 构建索引（离线）
1.批量向量化所有 chunks
2.faiss.normalize_L2(vectors) — 原地归一化
3.IndexFlatIP(dim).add(vectors)
4.持久化：.index 文件 + chunks.json
🔍 查询检索（在线）
1.向量化查询文本（同一模型）
2.faiss.normalize_L2(query_vec)
3.index.search(query_vec, top_k)
4.返回 scores + indices（余弦相似度）
💡 为什么 normalize_L2 + IndexFlatIP = 余弦相似度？
归一化后向量模长均为 1，此时内积 = cos θ。IndexFlatIP 返回的分数就是余弦相似度值，与手写 cosine_similarity() 函数在数学上完全一致。
⚠️ 双文件持久化：索引文件存向量矩阵，JSON 文件存 chunks 文本。两者通过相同下标对应，必须同步更新。
