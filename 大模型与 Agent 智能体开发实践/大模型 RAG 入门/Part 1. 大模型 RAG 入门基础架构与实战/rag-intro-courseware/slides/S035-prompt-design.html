RAG Prompt 设计：引用而非创作

好的 RAG Prompt 做三件事：指定参考资料、引导引用、处理兜底

❌ 没有 RAG 约束的 Prompt
你是一个助手，请回答用户的问题。

用户问题：年假可以申请几天？
→ 模型可能编造答案，无法溯源
VS
✅ RAG 标准 Prompt 结构
System：严格基于【参考资料】回答，不编造内容。资料不足时说明无法回答。
参考资料：【资料1】（来源：HR-Policy.pdf）年假制度……
用户问题：年假可以申请几天？
→ 回答有据可查，可追溯到具体文档

空结果兜底：检索结果为空时，仍构建合法 messages，让 LLM 告知「根据现有资料无法回答」
